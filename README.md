
# Alabamian Trakt Free


Объектно ориентированная система запуска и сборки фаззинг исследований.

Из системы была удалена прикладная составляющая не подлежащая публикации,
но вся базовая функциональность была сохранена и в дальнейшем будут
добавлены практические примеры применения на основе публично доступных
примеров свободного ПО.
